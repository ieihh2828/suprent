# suprent — анализ конкурентов на Авито

Парсер выдачи Авито для разбора рынка аренды сапбордов (Рязань) и
последующей сборки сайта бизнеса.

## Что делает скрипт

1. Читает список URL поисковых выдач Авито из `urls.txt`.
2. Открывает их по очереди в видимом Chromium, проходит пагинацию,
   собирает ссылки на все объявления.
3. Заходит на каждое объявление с задержкой 4–9 секунд и забирает:
   - заголовок, цену, период (за день/за час)
   - адрес/район
   - **полное описание** (без обрезки на «...»)
   - категорию (по хлебным крошкам)
   - имя продавца, тип (частник / компания), рейтинг, кол-во отзывов
   - дату регистрации продавца, дату публикации объявления
   - количество фото
   - id объявления и url
4. Сохраняет в `data/competitors.json` и `data/competitors.csv`
   (записывает прогресс каждые 5 объявлений — не страшно если прервёшь).

## Установка (Windows / macOS / Linux)

Нужен Python 3.10 или новее.

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

## Использование

1. Открой Авито в браузере, поставь фильтры (Рязань, нужная категория,
   поисковая фраза). Скопируй URL из адресной строки.
2. Открой `urls.txt`, удали примеры (строки с `#`), вставь свои URL,
   по одному на строку. Можно вписать сразу несколько — для разных
   категорий или соседних городов.
3. Запусти:

```bash
python avito_parser.py
```

Откроется окно браузера. **Не закрывай его** пока скрипт работает.
Можешь продолжать пользоваться компом — просто не трогай это окно.

## Если выскочит капча

Скрипт остановится и в терминале покажет:

```
>>> Captcha or block detected. Solve it in the browser window.
>>> Press ENTER here when you're done...
```

Реши капчу мышкой в открытом окне браузера, потом вернись в терминал
и нажми Enter — скрипт продолжит с того же места.

## Где результат

```
data/

└── competitors.csv    # удобно открыть в Excel / Numbers / Google Sheets
```

## Подсказки

- **Не запускай в headless-режиме**. Авито ловит безголовые браузеры
  моментально. Скрипт уже настроен на видимый режим.
- **Не уменьшай задержки** ниже 4 секунд между объявлениями.
- Если парсер часто ловит капчу — пауза 30 минут, и попробовать снова.
- Для одного города и одной категории обычно 30–80 объявлений на проход.
