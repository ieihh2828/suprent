# 🗺 Аудит Яндекс.Карт — конкуренты + своя карточка

Цель: понять, как выглядит ниша «аренда сапов» в Яндекс.Картах
по Рязани. Что есть у конкурентов, чего нет. Что нужно
докрутить в своей карточке **до** запуска продвижения.

Без этого аудита платное продвижение — это слепой выстрел.

---

## Часть 1. Поиск конкурентов в Яндекс.Картах

Открой в браузере **четыре** ссылки по очереди — это разные
запросы, по которым тебя могут искать клиенты:

1. https://yandex.ru/maps/11/ryazan/search/прокат%20сапов
2. https://yandex.ru/maps/11/ryazan/search/аренда%20сапбордов
3. https://yandex.ru/maps/11/ryazan/search/sup%20аренда
4. https://yandex.ru/maps/11/ryazan/search/сап%20прокат

В каждом — ползунок «город Рязань» (а не вся область).

По каждой ссылке выпиши **всех найденных** в таблицу ниже
(один блок = один игрок). Если один и тот же продавец
найден по нескольким запросам — он один раз.

## Часть 3. Особый раздел — ОТЗЫВЫ КОНКУРЕНТОВ

Это золото. У каждого ТОП-3 конкурентов **прочитай минимум
10 отзывов** (5 свежих + 5 негативных, если есть).

Выпиши:

```
КОНКУРЕНТ: [имя]

ЗА ЧТО ХВАЛЯТ (повторяющиеся):
  - ...
  - ...
  - ...

НА ЧТО ЖАЛУЮТСЯ (повторяющиеся):
  - ...
  - ...
  - ...

КАК ВЛАДЕЛЕЦ ОТВЕЧАЕТ НА КРИТИКУ:
  [хорошо / формально / не отвечает / агрессивно]
```

Жалобы конкурентов — это **готовое УТП** для тебя.
Если у троих разных арендодателей жалуются на грязные
сапы — твой пункт «мою каждый сап после клиента»
становится главным экраном на сайте.

## Часть 4. АУДИТ ТВОЕЙ КАРТОЧКИ (SUPRENT62)

Открой свою карточку Яндекс.Карт. Пройдись по чек-листу
и поставь честно: ✅ есть и хорошо / ⚠️ есть, но слабо /
❌ нет.

### 4.1 Базовая информация

```
[ ] Название карточки правильное
    (содержит ключи «прокат», «аренда», «сапы», «Рязань»?)
[ ] Категория выбрана точно
    (для тебя — «Прокат» + желательно «Спортивный инвентарь»)
[ ] Адрес соответствует факту выдачи
[ ] Телефон рабочий, отвечаешь
[ ] WhatsApp подключён к телефону
[ ] Сайт указан
[ ] ВК-группа указана
[ ] Режим работы заполнен (по сезону)
[ ] Сезонность отмечена («только летом»)
```

### 4.2 Фотографии (это самое важное)

```
[ ] Минимум 15-20 фото
[ ] Главное фото — продаёт (не стоковая картинка
    с интернета, а реальное)
[ ] Есть фото:
    [ ] сапов в воде на природе
    [ ] клиентов на сапах (с разрешения)
    [ ] комплекта оборудования (доска, насос, лиш, жилет)
    [ ] точки выдачи (как клиент её увидит, ориентир)
    [ ] процесса инструктажа
    [ ] видов с воды (то что увидит клиент когда покатается)
[ ] Подписи под каждым фото
[ ] Качество — нормальное (не размытые, не «фоткал на тапок»)
[ ] Видео есть (хоть одно — 30-секундное «как это выглядит»)
```

### 4.3 Описание

```
[ ] Заполнено (не пусто, не одним предложением)
[ ] Указан адрес выдачи словами
[ ] Указаны цены (хотя бы вилка)
[ ] Что в комплекте — перечислено
[ ] Чем ты отличаешься (1-2 фишки)
```

### 4.4 Прайс-лист (отдельная вкладка)

```
[ ] Прайс-лист подключён
[ ] Указаны позиции с ценами
[ ] Каждой позиции — фото
```

### 4.5 Услуги / особенности

```
[ ] Прокат инвентаря — отмечено
[ ] Принимаются карты — да/нет
[ ] Парковка рядом — да
[ ] Доставка — да
[ ] Возможна аренда от 1 единицы / группы
```

### 4.6 Отзывы

```
[ ] Сколько отзывов всего:        [...]
[ ] Средний рейтинг:               [...]
[ ] Свежий отзыв (за месяц):       [...]
[ ] Все негативные с ответом:      [...]
[ ] Есть ли проактивные ответы
    под позитивными отзывами:      [...]
```

### 4.7 Активность

```
[ ] Карточка обновляется (последнее обновление)
[ ] Есть посты в карточке (Я.Карты разрешает посты)
[ ] Привязан Я.Бизнес (для аналитики)
[ ] Подключена реклама в Я.Картах
```

## Часть 5. После аудита

Когда заполнишь Часть 2 (по конкурентам) и Часть 4
(по своей карточке), скинь сюда — я разверну:

1. **Тепловую карту**: где у тебя пробелы относительно
   ТОП-3 конкурентов. Что докрутить в первую очередь
2. **План фотосъёмки**: список конкретных фото которые надо
   доснять под Я.Карты
3. **Текст описания** для Я.Карт (короче чем на Авито,
   с другим акцентом)
4. **Список услуг и особенностей** для проставления галочек
5. **План работы с отзывами** — как тебе раскачать поток
   отзывов перед запуском платного продвижения
6. **Стратегию запуска платного продвижения**:
   геотаргетинг, ставки, ключи, бюджет на месяц
