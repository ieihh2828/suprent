## 2. Цены и штрафы — финальные

| Параметр | Значение |
|----------|----------|
| Аренда насоса электрического | **400 ₽** за весь срок аренды |
| Аренда жилета | **бесплатно** (только галочка) |

| **Штраф за возврат в грязном виде** | **500 ₽** *(понижено с 700)* |

## 3. Срок аренды — два режима

```
2.1. Срок аренды (отметить применимый вариант):
     ☐ Почасовая аренда: с __ : __ до __ : __, итого ___ час(а/ов).
     ☐ Аренда на сутки:  ___ сутки, возврат не позднее __ : __ последних суток.
```

Часовая → время. Суточная → количество суток + до какого времени вернуть. Никакого «времени для длинной аренды».

## 4. Оформление .docx

- Заголовок документа — Arial Bold 13 pt, центрирован.
- Заголовки разделов (1, 2, 3 …) — Arial Bold 11 pt.
- Подзаголовки (3.1, 3.2, 7.1) — Times Bold 10 pt.
- Основной текст — Times New Roman 10 pt, выравнивание по ширине.
- Курсивные сноски — Times Italic 9 pt, серый.
- Поля страницы узкие (1 см), межстрочный интервал 1.0 → влезает на 2 страницы A4.
- Шапка Арендатора — таблица 2 колонки (метка | поле), без видимых границ → строки не разъезжаются.
- Поля для заполнения — единые подчёркнутые ран-пробелы, не разрываются переносами.
- Плашки штрафа красным **больше нет** — штраф просто выделен жирным внутри п. 3.2.3.

## 5. Что Арендатор заполняет от руки (всего одно место)

В шапке (таблица):
- ФИО,
- адрес регистрации,
- паспорт серия/номер,
- кем и когда выдан,
- телефон.

В теле:
- дата заключения (одна, в шапке);
- кол-во комплектов в п. 1.2;
- галочки опций в п. 1.3;
- срок в п. 2.1 (либо часы, либо сутки);
- сумма аренды в п. 2.2.

Внизу — только подпись и расшифровка фамилии.

## 6. Что в .docx по сравнению с .md

`.docx` и `.md` синхронны по содержанию. `.docx` — это итоговый документ для печати; `.md` — текстовая версия для истории/правок и code-review. Любые изменения в скрипте генератора `tools/generate_contract_docx.py` нужно дублировать в `.md` (и наоборот) — сейчас оба файла обновлены вручную.
